# HomeLayout

`HomeLayout` — это компонент макета для [главной страницы](/guide/basic/home-page), отвечающий за интеграцию и отображение секций Hero, Features и Footer.

## Использование

Измените или переопределите его через [пользовательскую тему](/guide/basic/custom-theme):

```tsx title="theme/index.tsx"
import { HomeLayout as BasicHomeLayout } from '@rspress/core/theme-original';

export default function HomeLayout() {
  return <BasicHomeLayout />;
}
```

Компонент `HomeLayout` получает конфигурацию `hero` и `features` из метаданных через [`useFrontmatter`](/ui/hooks/use-frontmatter). Подробные параметры конфигурации приведены в разделе [Конфигурация метаданных](/api/config/config-frontmatter#hero).

### Пользовательские слоты

Используйте свойства слотов, чтобы вставить собственный контент перед каждой секцией и после неё:

```tsx title="theme/index.tsx"
import { HomeLayout as BasicHomeLayout } from '@rspress/core/theme-original';

export default function HomeLayout() {
  return (
    <BasicHomeLayout
      beforeHero={<div>Контент перед Hero</div>}
      afterHero={<div>Контент после Hero</div>}
      beforeFeatures={<div>Контент перед Features</div>}
      afterFeatures={<div>Контент после Features</div>}
      beforeHeroActions={<div>Контент перед кнопками Hero</div>}
      afterHeroActions={<div>Контент после кнопок Hero</div>}
    />
  );
}
```

## Пропсы

### beforeHero

- **Тип:** `React.ReactNode`

Пользовательский контент, вставляемый перед секцией Hero.

### afterHero

- **Тип:** `React.ReactNode`

Пользовательский контент, вставляемый после секции Hero.

### beforeHeroActions

- **Тип:** `React.ReactNode`

Пользовательский контент, вставляемый перед кнопками Hero и передаваемый компоненту [HomeHero](/ui/layout-components/home-hero).

### afterHeroActions

- **Тип:** `React.ReactNode`

Пользовательский контент, вставляемый после кнопок Hero и передаваемый компоненту [HomeHero](/ui/layout-components/home-hero).

### beforeFeatures

- **Тип:** `React.ReactNode`

Пользовательский контент, вставляемый перед секцией Features.

### afterFeatures

- **Тип:** `React.ReactNode`

Пользовательский контент, вставляемый после секции Features.

## Вложенные компоненты

`HomeLayout` внутри использует следующие компоненты:

- [HomeBackground](/ui/layout-components/home-background) — фон главной страницы
- [HomeHero](/ui/layout-components/home-hero) — секция Hero
- [HomeFeature](/ui/layout-components/home-feature) — секция Features
- [HomeFooter](/ui/layout-components/home-footer) — секция Footer

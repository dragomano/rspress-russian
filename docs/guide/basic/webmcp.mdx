# WebMCP

<VersionBadge version="2.1.0" />

Rspress может предоставлять инструменты документации браузерным агентам через нативный [WebMCP API](https://developer.chrome.com/docs/ai/webmcp/imperative-api). Функция встроена в ядро и включена по умолчанию. Включите генерацию Markdown, чтобы стали доступны все шесть инструментов:

```ts title="rspress.config.ts"
import { defineConfig } from '@rspress/core';

export default defineConfig({
  llms: true,
});
```

Установите `webMcp: false`, чтобы отключить встроенные инструменты Rspress. Хук [`useWebMcp`](/ui/hooks/use-web-mcp) по-прежнему доступен для регистрации собственных инструментов.

WebMCP экспериментален и требует браузера с включённым `document.modelContext` в безопасном контексте, например HTTPS или localhost. Браузеры без поддержки продолжают отображать сайт как обычно.

Справочник по настройке см. в разделе [Конфигурация ИИ](/api/config/config-agent#webmcp).

## Встроенные инструменты

| Инструмент                 | Назначение                                                                                                                  |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `rspress_get_site_info`    | Метаданные сайта, локали, версии, навигация и активная боковая панель.                                                      |
| `rspress_list_pages`       | Фильтрация и постраничный вывод метаданных страниц; по умолчанию используются активный язык и версия. Работает независимо от поиска. |
| `rspress_get_page`         | Чтение метаданных, frontmatter, оглавления и Markdown из SSG-MD для известного маршрута без перехода (включается при `llms: true`). |
| `rspress_get_current_page` | Чтение метаданных, frontmatter, оглавления и Markdown из SSG-MD для текущей страницы (включается при `llms: true`).         |
| `rspress_search_docs`      | Поиск по локальному индексу документации для активного языка и версии (только локальный поиск стандартной темы).            |
| `rspress_navigate`         | Переход к известному внутреннему маршруту с последующим возвратом метаданных страницы, маршрутов разделов и ссылок на предыдущую и следующую страницы. |

Пути маршрутов указываются без настроенного `base` и поддерживают строки запроса и хэши.

`rspress_list_pages` принимает `query`, `lang`, `version`, `limit` (от 1 до 100, по умолчанию 50) и `offset` (по умолчанию 0). Запрос сопоставляется с заголовками страниц, описаниями, маршрутами и заголовками разделов. `rspress_search_docs` принимает `query` и `limit` (от 1 до 20, по умолчанию 10).

## Кросс-доменные агенты

Используйте [`webMcp.exposedTo`](/api/config/config-agent#webmcp), чтобы разрешить определённым безопасным источникам обнаруживать инструменты.

## Собственные инструменты

Используйте [`useWebMcp`](/ui/hooks/use-web-mcp) из `@rspress/core/runtime`, чтобы регистрировать инструменты в собственных компонентах. Инструменты автоматически удаляются при размонтировании компонента.

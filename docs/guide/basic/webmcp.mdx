# WebMCP

<VersionBadge version="2.1.0" />

Rspress включает [`webMcp`](/api/config/config-agent#webmcp) по умолчанию, поэтому агенты могут использовать [WebMCP](https://developer.chrome.com/docs/ai/webmcp), чтобы искать, читать и перемещаться по документации Rspress. Подробнее см. в [ChatGPT - Site tools](https://learn.chatgpt.com/docs/webmcp).

Если список пуст или вам не удалось получить к нему доступ, сообщите, что именно произошло."

```ts title="rspress.config.ts"
import { defineConfig } from '@rspress/core';

export default defineConfig({
  webMcp: true, // значение по умолчанию
});
```

Установите `webMcp: false`, чтобы отключить встроенные инструменты Rspress. Хук [`useWebMcp`](/ui/hooks/use-web-mcp) по-прежнему доступен для регистрации собственных инструментов.

## Встроенные инструменты

| Инструмент            | Назначение                                                                                                                                             |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------                       |
| `get_site_info`       | Метаданные сайта, локали, версии, навигация и активная боковая панель.                                                                                 |
| `list_pages`          | Фильтрация и постраничный вывод метаданных страниц; по умолчанию используются активный язык и версия. Работает независимо от поиска.                   |
| `get_page`            | Чтение метаданных, frontmatter, оглавления и Markdown для известного маршрута без перехода (включается вместе с [SSG-MD](/guide/basic/ssg-md)).        |
| `get_current_page`    | Чтение метаданных, frontmatter, оглавления и Markdown для текущей страницы (включается вместе с [SSG-MD](/guide/basic/ssg-md)).                        |
| `search_docs`         | Поиск по локальному индексу документации для активного языка и версии (только локальный поиск стандартной темы).                                       |
| `navigate`            | Переход к известному внутреннему маршруту с последующим возвратом метаданных страницы, маршрутов разделов и ссылок на предыдущую и следующую страницы. |

## Кросс-доменные агенты

Используйте [`webMcp.exposedTo`](/api/config/config-agent#webmcp), чтобы разрешить определённым безопасным источникам обнаруживать инструменты.

## Собственные инструменты

Используйте [`useWebMcp`](/ui/hooks/use-web-mcp) из `@rspress/core/runtime`, чтобы регистрировать инструменты в собственных компонентах. Инструменты автоматически удаляются при размонтировании компонента.

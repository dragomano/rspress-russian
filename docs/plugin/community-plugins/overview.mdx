# Обзор

## Плагины сообщества

Плагины сообщества перечислены в алфавитном порядке по имени пакета. Мы будем рады PR, добавляющим ваши опубликованные плагины в этот список!

- [@kazamori/rspress-plugin-git-diff](https://github.com/kazamori/rspress-plugin-git-diff): показывает историю git для страниц документации: изменения, отмеченные прямо на странице, страница недавних изменений и история каждой страницы.
- [@seshuk/rspress-plugin-scalar](https://github.com/maximseshuk/rspress-plugin-scalar): рендеринг интерактивных страниц справочника API Scalar из спецификаций OpenAPI.
- [rspress-language-tabs](https://github.com/maccuaa/rspress-language-tabs): компонент Rspress для создания примеров кода с вкладками и иконками языков программирования.
- [rspress-plugin-align-image](https://github.com/rstackjs/rspress-plugins/tree/main/packages/rspress-plugin-align-image): плагин Rspress для выравнивания изображений в разметке Markdown.
- [rspress-plugin-annotation-words](https://github.com/2heal1/rspress-plugin-annotation-words): плагин Rspress для поддержки аннотационных слов.
- [rspress-plugin-auto-meta](https://github.com/smileluck/rspress-plugin-auto-meta.git): плагин для Rspress, который автоматически генерирует метаданные навигации для вашей документации.
- [rspress-plugin-auto-sidebar](https://github.com/buyfakett/rspress-plugin-auto-sidebar.git): автоматическая генерация боковой панели на основе конфигурации навигационной панели.
- [rspress-plugin-blog-list](https://github.com/buyfakett/rspress-plugin-blog-list.git): интеграция списка блогов в Rspress.
- [rspress-plugin-changelog](https://github.com/baranwang/rspress-plugin-changelog): генерация страниц журнала изменений с получением информации о релизах из репозиториев GitHub и GitLab.
- [rspress-plugin-clarity](https://github.com/jl917/rspress-plugin-clarity): плагин Rspress для интеграции с [Clarity](https://clarity.microsoft.com/).
- [rspress-plugin-comments](https://github.com/kalicyh/rspress-plugin-comments): предоставляет комментарии к страницам и комментарии к выделенному тексту для Rspress, с поддержкой авторазвёртывания бэкенда и опциональным входом через OAuth Gitea.
- [rspress-plugin-directives](https://github.com/rstackjs/rspress-plugins/tree/main/packages/rspress-plugin-directives): плагин Rspress для поддержки пользовательских директив.
- [rspress-plugin-file-tree](https://github.com/rstackjs/rspress-plugins/tree/main/packages/rspress-plugin-file-tree): плагин Rspress, добавляющий древовидное представление для отображения структуры файлов.
- [rspress-plugin-font-figtree](https://github.com/maccuaa/rspress-plugin-font-figtree): использование Figtree в качестве шрифта по умолчанию на сайте Rspress.
- [rspress-plugin-font-open-sans](https://github.com/rstackjs/rspress-plugin-font-open-sans): использование шрифта Open Sans в качестве шрифта по умолчанию на сайте Rspress.
- [rspress-plugin-gh-pages](https://github.com/rstackjs/rspress-plugins/tree/main/packages/rspress-plugin-gh-pages): плагин Rspress для добавления поддержки автоматического развертывания на GitHub Pages.

- [rspress-plugin-typesense](https://github.com/typesense/rspress-plugin-typesense): плагин Rspress, который заменяет встроенный поиск на [Typesense](https://typesense.org/) — открытую, устойчивую к опечаткам поисковую систему.
- [rspress-plugin-vercel-analytics](https://github.com/rstackjs/rspress-plugins/tree/main/packages/rspress-plugin-vercel-analytics): плагин Rspress для интеграции с Vercel Analytics.
- [rspress-plugin-viz](https://github.com/elecmonkey/rspress-plugin-viz): добавляет в Rspress поддержку рендеринга диаграмм Graphviz с помощью [@viz-js/viz](https://github.com/mdaines/viz-js/).
- [zephyr-rspress-plugin](https://www.npmjs.com/package/zephyr-rspress-plugin): плагин Rspress для развёртывания приложений с помощью Zephyr Cloud.

## Вклад в плагины сообщества

Вклады сообщества в плагины Rspress приветствуются! Имена npm-пакетов плагинов должны следовать соглашению с префиксом `rspress-plugin-`.

Вы можете внести свой вклад следующими способами:

- Разработайте и опубликуйте плагин в собственном репозитории, затем отправьте PR, чтобы добавить его в список плагинов сообщества на этой странице.
- Внесите вклад напрямую в репозиторий [rspress-plugins](https://github.com/rstackjs/rspress-plugins), уже содержащий несколько плагинов сообщества, которые могут служить примером.
